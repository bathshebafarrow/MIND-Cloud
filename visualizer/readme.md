# VISUALIZER

The visualizer generates visualizations of EEG data.

The current visualization are generated using the MNE library. Refer to website for other visualizations: https://mne.tools/stable/auto_examples/visualization/index.html

MNE is also used to read data from various EEG file types. Refer to methods for reading files here: https://mne.tools/stable/api/reading_raw_data.html
